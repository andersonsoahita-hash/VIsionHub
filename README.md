# VisionHub by Stephen

Outil d'aide à la décision pour tester un projet d'entreprise avant de dépenser : idée, preuves, chiffres, risques, simulateur de marché, validation sur 7 dimensions, rapport.

- Application en un seul fichier : `index.html` (aucune installation, les données restent dans le navigateur).
- Idées d'entreprise pour étudiants malgaches (moins de 1 000 000 Ar) selon le budget.
- Bouton « Envoyer vers le Suivi » : copie le projet complet pour l'importer dans [VisionHub Suivi](https://github.com/andersonsoahita-hash/VisionHub-Suivi).

Les chiffres des exemples sont des estimations de départ, à vérifier avec de vrais prix. Le plan ne prédit pas le succès.
